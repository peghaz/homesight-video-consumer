Python API
==========

Import the public interface with ``import homesight_core as core``. Configuration
fields accept keyword arguments; their descriptions state native defaults. The
typing stubs mark unspecified default values as ``...`` in generated signatures.
All blocking native operations exposed by these interfaces release the GIL.
